# Controls reference

Controls are remappable from **Settings → Controls**. Touch controls can be resized, repositioned, mirrored, and faded from **Settings → Touch**.

## Keyboard defaults

| Action | Default |
|---|---|
| Move | Arrow keys or WASD |
| Primary action / sword / confirm | Space or Z |
| Secondary equipped action | X |
| Interact / talk / use | E or Enter |
| Guard / parry | Shift |
| Pause | Escape |
| Inventory | I |
| World map | M |
| Fast travel | Open the world map at a restored signal tower |
| Skip cutscene | Hold Cancel/Escape |
| Fast-forward cutscene/dialogue | Hold Confirm |
| Performance overlay | F3 |
| Developer console | F10 in development-enabled builds only |

## Controller defaults

| Action | Typical mapping |
|---|---|
| Move | Left stick or D-pad |
| Primary / confirm | South face button |
| Secondary | West face button |
| Guard / parry | Shoulder or trigger |
| Interact | East face button |
| Pause | Start/Menu |
| Inventory/map | View/Select or assigned shoulder buttons |

Browser gamepad labels and button indexes vary. Remap controls for the connected device before extended play.

## Touch

- Left-side virtual joystick controls movement.
- Large right-side buttons provide primary, secondary, interact, guard, pause, and menu actions.
- Standard, left-handed, compact, and custom layouts are available.
- Custom mode allows dragging every control.
- Size and opacity are adjustable.

## Accessibility controls

- Hold-or-toggle behavior can be selected for supported actions.
- Aim assistance, longer parry timing, navigation hints, interaction indicators, and touch customization are optional.
- Public builds retain keyboard, controller, and touch support simultaneously; the currently active input source updates prompts where practical.
